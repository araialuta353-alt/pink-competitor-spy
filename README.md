# 🕵️‍♀️ Pink Competitor Spy

Skill Claude pour analyser les contenus Instagram et TikTok **publics** de concurrents et créer des idées **originales** pour Pink Digital Studio.

## Contenu

```
.claude/skills/pink-competitor-spy/
├── SKILL.md                    ← les instructions du Skill
└── references/grille-analyse.md ← accroches, formats, CTA, formules de performance
pink-competitor-spy.zip          ← à importer dans l'app Claude
```

## Installer sur iPhone (app Claude)

1. Télécharge `pink-competitor-spy.zip` sur ton iPhone (depuis GitHub : ouvre le fichier → « Download »).
2. Sur claude.ai (Safari) ou dans l'app : **Réglages → Capacités → Skills → Importer un skill**, puis choisis le ZIP.
3. Active le Skill.

## Utiliser

Dans une conversation Claude :

1. Envoie 2 à 4 **captures d'écran** : début du Reel (accroche), légende, compteurs, grille du profil avec les vues.
2. Écris par exemple : « Pink Competitor Spy : analyse ce Reel de @compte ».
3. Tu reçois un rapport : top contenus, décryptage, méthodes, 3 idées Pink Digital Studio, prochaine action.

## Coût

Aucun outil payant : seulement ton abonnement Claude actuel. Pas de scraping, pas d'API Instagram.
